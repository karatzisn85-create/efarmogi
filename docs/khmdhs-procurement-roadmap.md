# Οδηγός αξιοποίησης δεδομένων ΚΗΜΔΗΣ (διαγωνισμοί)

Σκοπός: καλύτερη χρήση των δεδομένων προκήρυξης (ΑΔΑΜ **PROC**), στατιστικών, προθεσμιών και **Ημερολογίου Προθεσμιών** στο ERGOHUB.

---

## Τρέχουσα κατάσταση

| Πηγή | Τι αποθηκεύουμε | Τι κάνουμε σήμερα |
|------|-----------------|-------------------|
| **PROC (προκήρυξη)** | ~30 πεδία (τίτλος, διαδικασία, καταληκτική, αξίες, CPV, χρηματοδότηση, ματαίωση κ.λπ.) | Auto-fill διαδικασίας + ημ. έναρξης, προβολή σε κάρτα/modal |
| **SYMV (σύμβαση)** | Ανάδοχος, ΑΦΜ, αναθέτουσα | Αναζήτηση/φίλτρα ανάδοχου |
| **adamChain API** | Διαθέσιμο στο backend | Δεν χρησιμοποιείται ακόμα στο UI |

Κρίσιμο πεδίο: **`finalSubmissionDate`** (καταληκτική υποβολής προσφορών) — τροφοδοτεί widget, φίλτρα, countdown (Φάση 1) και θα τροφοδοτήσει το Ημερολόγιο Προθεσμιών (Φάση 3).

## Φάση 3 — Ημερολόγιο Προθεσμιών

### Επίσημο όνομα & πρόσβαση UI

| Στοιχείο | Απόφαση |
|----------|---------|
| **Όνομα module** | **Ημερολόγιο Προθεσμιών** |
| **Τοποθέτηση** | **Μοναδικό κουμπί** στην αριστερή μπάρα (sidebar), **εκτός** accordion κατηγοριών (Έργα / Διαδικασίες / Εργαλεία / Σύστημα) |
| **Θέση προτεινόμενη** | Μετά το «Γρήγορη Αναζήτηση», πριν την πρώτη κατηγορία — πάντα ορατό, χωρίς expand |
| **Ρόλοι πρόσβασης** | `SUPERADMIN`, `ADMIN`, `ENGINEER` |
| **Μηχανικοί** | Βλέπουν **μόνο** προθεσμίες διαγωνισμών για υποέργα που τους αφορούν (`supervisorEngineerIds` / `assignedSupervisors`) |
| **USER** | Χωρίς πρόσβαση |

**Συνύπαρξη:** Το widget Φάσης 1 («επερχόμενες καταληκτικές») **παραμένει** ως shortcut· το Ημερολόγιο Προθεσμιών είναι η πλήρης οθόνη.

---

### Αποφάσεις σχεδιασμού (lock-in)

| # | Θέμα | Απόφαση |
|---|------|---------|
| 1 | **Ισχύς προσφορών** (`offersValidTime`) | Η **καταληκτική ημερομηνία** (`finalSubmissionDate`) είναι το **όριο αναφοράς** — η λήξη ισχύος προσφορών υπολογίζεται από αυτή + διάρκεια (όχι άλλο anchor) |
| 2 | **Κανόνας 12 μηνών** | **Β** — εμφάνιση **μόνο υπαρχουσών παραβάσεων** (αναδρομικός έλεγχος), όχι προληπτικές ημερομηνίες «λήξης αναμονής» |
| 3 | **Πεδίο χρόνου** | **Μόνο ενεργά** υποέργα — όχι ιστορικά events για συμβασιοποιημένα/ολοκληρωμένα (συνεπές με `projectProcurementPhaseConcluded`) |
| 4 | **Καταληκτική vs ημ. έναρξης** | **Δεν υπάρχει σύγκρουση** — η καταληκτική **λήγει μόνο από ΚΗΜΔΗΣ**· στη χειροκίνητη διαδικασία δεν καταγράφεται καταληκτική |
| 5 | **Widget vs ημερολόγιο** | **Συνύπαρξη** |
| 6 | **Email υπενθυμίσεις** | Ρύθμιση από **SUPERADMIN → Σύστημα → «Ρυθμίσεις Ημερολογίου»** (βλ. παρακάτω) |
| 7 | **Scope ημερολογίου** | **Μόνο διαγωνισμοί** (ΚΗΜΔΗΣ PROC + compliance) — όχι ενιαίο ημερολόγιο ΑΕΠΟ/εργασιών |
| 8 | **Single source of truth** | Events παράγονται **runtime** από snapshots — χωρίς duplicate storage |

---

### Events στο ημερολόγιο

| Τύπος event | Πηγή | Προτεραιότητα | Σημειώσεις |
|-------------|------|---------------|------------|
| Καταληκτική υποβολής προσφορών | `finalSubmissionDate` | **Υψηλή** | Κύριο event· μόνο με ΑΔΑΜ PROC |
| Λήξη ισχύος προσφορών | `finalSubmissionDate` + `offersValidTime` + unit | Μέτρια | Anchor = καταληκτική |
| Έκδοση / πρωτόκολλο | `signedDate` | Μέτρια | Μόνο ενεργά |
| Καταχώριση ΚΗΜΔΗΣ | `submissionDate` | Χαμηλή | Μόνο ενεργά |
| Έναρξη διαδικασίας | `contractProcessStartDate` | Μέτρια | Χωρίς επικάλυψη με καταληκτική |
| Παράβαση 12μ. (απευθείας) | `directAssignmentCompliance` | **Υψηλή** | Μόνο **εντοπισμένες παραβάσεις** (Β) |

**Κριτήριο «ενεργό»:** Κατάσταση **«ΣΕ ΔΙΑΔΙΚΑΣΙΑ ΣΥΝΑΨΗΣ ΣΥΜΒΑΣΗΣ»** + ΑΔΑΜ PROC + **όχι** `projectProcurementPhaseConcluded` + **όχι** ματαιωμένος (`cancelled`).

### UI — Ημερολόγιο Προθεσμιών

- **Μηνιαία προβολή** (grid ημερολογίου)
- **Λίστα** «Επόμενες 30 / 60 / 90 ημέρες»
- **Φίλτρα:** καταληκτικές διαγωνισμού / παραβάσεις 12μ. / όλα
- **Κλικ event** → άνοιγμα λεπτομερειών υποέργου + expand πάνελ ΚΗΜΔΗΣ

**Component προτεινόμενο:** `src/components/ProcurementCalendar.js` (ή `DeadlinesCalendar.js`)

**Helper προτεινόμενο:** `src/utils/procurementCalendarEvents.js` — `buildProcurementCalendarEvents(projects, { userRole, currentUser })`

### Ρυθμίσεις Ημερολογίου (SUPERADMIN)

Νέο κουμπί στην κατηγορία **Σύστημα** (μόνο SUPERADMIN):

**«Ρυθμίσεις Ημερολογίου»**

| Ρύθμιση | Περιγραφή |
|---------|-----------|
| Αποστολή email | Ενεργό / ανενεργό |
| Ρόλοι παραληπτών | Πολλαπλή επιλογή: ADMIN, ENGINEER, … |
| Συγκεκριμένοι χρήστες | Προαιρετική λίστα usernames (override/επιπλέον) |
| Ημέρες πριν | Πολλαπλές τιμές (π.χ. 7, 3, 1, 0) |
| Επανάληψη σε κίνδυνο | Πόσες φορές / ποιο interval όταν η προθεσμία είναι «επείγουσα» (≤7 ημέρες) |

**Αποθήκευση:** `calendar_config.json` (ή επέκταση `email_config.json`) εντός `dataDir` — κρυπτογραφημένα credentials όπως SMTP.

**Email template:** Επίσημο HTML (όπως task assignment emails) — τίτλος υποέργου, ΑΔΑΜ PROC, ημερομηνία/ώρα καταληκτικής, ημέρες που απομένουν, link/open hint. Πεδία μέσω `escapeHtml()`.

**Background job:** `electron.js` — ημερήσιος έλεγχος (ή κατά startup + timer), αποστολή βάσει ρυθμίσεων, audit log χωρίς SMTP password.

## Φάση 4 — Νέα δεδομένα από ΚΗΜΔΗΣ

1. **Αλυσίδα ΑΔΑΜ (`adamChain`)** — timeline REQ → PROC → AWRD → SYMV
2. **Περιοδικό refresh snapshots** — ενεργά υποέργα, audit αλλαγών καταληκτικής/ματαίωσης
3. **Πλουσιότερο contract snapshot** — ποσό, ημ. υπογραφής, διάρκεια
4. **Αντικείμενα διαγωνισμού** — περιγραφές από `objectDetails[]`
