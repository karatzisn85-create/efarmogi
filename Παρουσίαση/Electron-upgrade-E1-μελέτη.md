# Μελέτη αναβάθμισης Electron (E1) — ERGOHUB

**Κατάσταση:** Ολοκληρώθηκε ως μελέτη (Αύγουστος 2026)  
**Εφαρμογή:** ERGOHUB v1.4.47  
**Τρέχων κινητήρας:** Electron **25.9.8** (+ electron-builder **23.6.0**)  
**Σημαντικό:** Δεν έχει γίνει ακόμα αλλαγή έκδοσης. Αυτή η μελέτη είναι το δίχτυ πριν από οποιοδήποτε E2.

---

## 1. Γιατί μας αφορά

Το Electron 25 **δεν λαμβάνει πλέον ενημερώσεις ασφαλείας** (EOL από Δεκ. 2023).  
Η επίσημη πολιτική Electron: υποστηρίζονται μόνο οι **3 πιο πρόσφατες** σταθερές εκδόσεις (σήμερα περίπου 40–42).

Η αναβάθμιση **δεν αλλάζει** τις οθόνες ή τα δεδομένα του δήμου. Αλλάζει τον κινητήρα μέσα στο `.exe`.  
Αν κάτι πάει στραβά: **επιστροφή στο 25.9.x** μέσω Git + παλιό installer.

## 4. Προτεινόμενη στρατηγική αναβάθμισης (όχι άλμα)

**Μην πάμε απευθείας 25 → 42.** Σε βήματα, με δοκιμαστικό `.exe` και checklist σε κάθε στάση:

| Φάση | Στόχος Electron | Σκοπός |
|------|-----------------|--------|
| **A** | **28.x** | Πρώτο ασφαλές σκαλοπάτι μετά το 25 (Chromium/Node πιο κοντά) |
| **B** | **33.x** | Μεγάλο ορόσημο (Node 20, Chromium 130)· έλεγχος native / builder |
| **C** | **Τρέχουσα υποστηριζόμενη** (π.χ. 40+) | Μόνο αφού περάσουν A+B + checklist |

Παράλληλα: αναβάθμιση **electron-builder** όταν το απαιτεί η νέα στοίβα (το 23.6 μπορεί να μην φτάνει για πολύ νεότερο Electron).

Κάθε φάση:
1. Ξεχωριστό git branch  
2. `npm install` + τρέξιμο unit tests  
3. Build δοκιμαστικού portable `.exe`  
4. Checklist smoke (βλ. αρχείο checklist)  
5. Αν αποτύχει → πίσω στο προηγούμενο commit / Electron 25  

---

## 5. Γνωστά σημεία κώδικα προς προσοχή πριν/κατά το E2

1. **`webContents.on('crashed')`** → αντικατάσταση/συμπλήρωση με `render-process-gone` σε νεότερο Electron.  
2. **`webSecurity: false` + `--no-sandbox`** — να μην αλλάξουν στην ίδια μέρα με το upgrade (εκκρεμότητα S4 χωριστά).  
3. **electron-builder 23** — έλεγχος συμβατότητας πριν το build του φάσης A/B.  
4. **react-pdf / pdfjs-dist** — smoke σε προβολή PDF μετά από αλλαγή Chromium.  
5. **safeStorage** — δοκιμή αποθήκευσης/ανάγνωσης κωδικού email μετά το upgrade.
